# 찜꽁 최종 MVP 시연 영상 (main · 2026-11-02 기준)

- `jjimkkong-demo.mp4` — 1280×720, 7분 11초, 자막(화면 안) + 한국어 나레이션
- `jjimkkong-demo.srt` — 자막 파일 (유튜브 등에 따로 올릴 때)
- 기준 코드: `origin/main` 8e149d2 (2026-11-02). 데모 서버(`CAFE24_MOCK=1`)를 켜고 Playwright로 화면을 녹화하면서 단계마다 자막을 띄우고, edge-tts(ko-KR-SunHiNeural) 나레이션을 ffmpeg로 합쳤어요. 같은 흐름은 `/demo` 안내대로 손으로도 재현할 수 있어요.
- 영상 속 모의 쇼핑몰은 실제 테스트몰 ‘베베누리’와 같은 모양(로고 · 메뉴 · 상품 상세 배치)으로 꾸민 녹화용 스킨이에요. 저장소의 데모 페이지(LINEN & CO.)와는 모양만 다르고 동작은 같아요.
