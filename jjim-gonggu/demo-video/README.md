## 캐릭터 버전은 어떻게 만들었나 (전부 로컬)

1. 대본(`script-jjimkkong.md`) → edge-tts `ko-KR-SunHiNeural`(음높이 +25Hz · 속도 +6%)로 24줄 음성 생성
2. 로컬 ComfyUI(RTX 5090) · **Wan2.2 S2V 14B**(fp8) + lightx2v 4단계 LoRA · 640px · 16fps — 캐릭터 그림 1장 + 대사 음성으로 말하는 캐릭터 클립 24개 생성 (4.8초 단위 Extend, 총 약 1시간)
3. 화면 녹화(자막 없음) 위에 ffmpeg로 캐릭터 클립을 원형 마스크 + 분홍 테두리로 합성. 대사가 시작되면 아래에서 튀어오르고, 끝나면 내려가요.
4. 외부 유료 서비스(힉스필드 등)는 쓰지 않았어요.
