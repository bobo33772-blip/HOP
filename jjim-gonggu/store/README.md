## 권한 사용 소명 (권한 10개)

| 권한 | 사용 이유 |
|---|---|
| 상품 읽기 `mall.read_product` | 공구를 열 상품 이름 · 가격 · 품절 여부를 불러옵니다. |
| 개인화정보 읽기 `mall.read_personal` | 상품을 장바구니에 담은 회원을 찾아 공구 초대 대상으로 삼습니다. |
| 회원 읽기 `mall.read_customer` | 탈퇴한 회원인지 회원 조회로 확인해, 탈퇴 회원의 회원 ID를 공구 기록에서 지웁니다. |
| 프로모션 읽기 `mall.read_promotion` | 공구 쿠폰 발급 상태를 확인합니다. |
| 프로모션 쓰기 `mall.write_promotion` | 목표를 달성하면 신청 회원에게만 쓸 수 있는 1회용 할인 쿠폰을 만들고 발급합니다. |
| 주문 읽기 `mall.read_order` | 공구 쿠폰으로 결제된 주문만 집계해 확정 수량을 계산합니다. |
| 알림 읽기 `mall.read_notification` | 등록된 문자 발신번호를 확인합니다. |
| 알림 쓰기 `mall.write_notification` | 공구 초대와 결과 안내 문자를 판매자 SMS로 보냅니다. 수신거부 고객은 카페24가 자동으로 제외합니다. |
| 앱 읽기 `mall.read_application` | 설치된 위젯 스크립트 상태를 확인합니다. |
| 앱 쓰기 `mall.write_application` | 상품 페이지에 공구 진행률 위젯 스크립트를 설치합니다. |

> 이 표는 `app/src/lib/cafe24/scopes.ts`와 같아야 해요. 권한을 바꾸면 둘 다 고쳐요.

## 심사 담당자 시험 순서

데이터가 없는 새 쇼핑몰에서는 공구를 열 대상(알림 신청 · 장바구니 고객)이 없어서 먼저 대상을 만들어야 해요. 스토어 FAQ에도 같은 순서를 넣었어요.

1. 앱을 설치하고 찜꽁 홈의 **시작하기**에서 브랜드명 · 문자 발신번호 · 080 수신거부 번호를 저장해요(카페24 SMS 충전 필요).
2. 상품 하나를 품절(재고 0, 진열함 · 판매함 그대로)로 바꿔요.
3. 쇼핑몰에 **테스트 회원으로 로그인**해 그 상품 페이지 구매 버튼 아래 **'재입고 · 공구 알림 받기'**를 누르거나, 다른 상품을 장바구니에 담아요.
4. 찜꽁 **새 공구** → 상품 고르기(목록이 비면 '다시 수집') → 목표 수량 · 공구가 · 마감 → 미리보기 → **공구 열기**. 초대 문자가 예약돼요(밤 9시~오전 8시는 오전 8시로).
5. 상품 페이지에 진행률 위젯이 보이고, 로그인한 회원은 결제 없이 **참여 신청**할 수 있어요.
6. 목표를 채우고 마감되면 신청 회원에게 1회용 할인 쿠폰이 발급되고, 결과는 **내 공구** · **리포트 링크**에서 봐요.
