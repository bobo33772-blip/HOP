공용 파일 규칙

어느 레인에도 속하지 않는 파일이에요. 여기를 고치는 PR이 충돌의 대부분을 만들어요.

공용 파일 목록console/provider.tsx · console/types.ts · console/format.ts · db/schema.ts + drizzle/ · engine/campaigns.ts · lib/core/* · globals.css · lib/console-actions.ts
작게, 먼저, 따로공용 파일만 바꾸는 작은 PR을 먼저 올려 머지한 뒤, 그 위에서 내 화면 PR을 이어요. 화면 PR 안에 공용 파일 변경을 섞지 않아요.
알리고 체크하기고치기 전에 작업카드 메모에 "types.ts에 X 필드 추가 예정"처럼 적고, PR 신청서의 "같이 쓰는 파일" 체크박스를 체크해요.
DB 구조(schema · drizzle)한 번에 한 PR만. 정본에 합친 뒤에 운영 DB에 반영해요. 같은 주에 두 레인이 schema를 고쳐야 하면 한 PR로 합쳐요.
리뷰 짝내 PR은 다음 번호 레인이 봐요. 서로의 경계 파일을 아는 사람이 리뷰하게 돼요.1→22→33→44→55→1
매일 pull작업 시작 전 git switch main && git pull 뒤 브랜치를 만들고, 오래 가는 브랜치는 이틀에 한 번 git merge origin/main으로 정본을 받아요.
