## 2026-10-08 · 두 MVP 통합
4주 파일럿 MVP(Node 단독 서버, SQLite)와 스토어 출시용 MVP(Next.js, Drizzle)를 이 앱 하나로 합쳤다.
- 공구 엔진(개설·신청·판정·쿠폰·문자·결제 집계·대사·리포트·판정표)을 Postgres(Drizzle)로 옮기고, 흐름 테스트를 그대로 옮겨 같은 동작을 확인했다.
- 운영자 화면(`/admin`), 판매자 리포트(`/r/<토큰>`), 위젯(`/widget.js` + `/api/public/…`), 데모(`/demo`)를 붙였다.
- 정기 작업: 서버 안 30초(`instrumentation.ts`) 또는 외부 크론(`/api/cron/tick`). 문자는 선점 후 발송해 중복 발송을 막는다.
- 마이그레이션은 운영 DB가 아직 없어 `0000_init` 하나로 새로 만들었다.

## 1단계에서 확정할 것 (테스트몰 PoC)
코드에 `VERIFY` / `⚠ PoC 체크`로 표시해 둔 가정들 (README의 표 참고):
1. 앱 실행 HMAC 서명 대상 문자열 → `src/lib/cafe24/hmac.ts`
2. 웹훅 `X-API-Key` 검증 방식·trace id 헤더 → `src/app/api/cafe24/webhooks/route.ts`
3. API 요청·응답 필드명 (쿠폰 생성·발급 내역, SMS, 스크립트태그, 주문) → `src/lib/cafe24/api.ts`, 응답 샘플을 `tests/fixtures/`에 저장
4. P2 위젯 회원 검증(지금은 연동 모드에서 모든 신청 거절) · P3 쿠폰 1,000명 · P8 찜 100명 초과 · P9 개인정보 설정 · P10 첫 수집 시간
5. P7 심사 전 지정 몰 설치 가능 여부 (`/api/cafe24/install`)

## 7단계 배포 전 체크리스트
