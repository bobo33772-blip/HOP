# 파일럿 판매자 동의 받기 (#115)

스토어 승인 전에는 설치 링크로 파일럿 몰을 직접 연결해요. 이때는 카페24 권한 동의만 남고, 찜꽁 이용약관 · 개인정보 처리방침에 동의했다는 기록이 없어요.
쇼핑몰 고객 정보는 판매자가 주인이고 찜꽁은 **수탁자**라서, 위탁 내용을 문서로 남겨야 해요(개인정보 보호법 제26조). 그래서 설치 링크를 보내기 전에 아래 동의를 이메일이나 메신저로 받아 두세요.

## 몇 곳까지

- 카페24 개발자센터 이용약관 첨부1 ④: **심사 전 테스트 설치는 앱 하나당 쇼핑몰 5개까지**예요.
- 보성 · 이규현 테스트몰도 5개 안에 들어가요. 그래서 승인 전 실제 파일럿 몰은 **3곳 정도**예요. 필요 없는 테스트 설치는 지워서 자리를 비워 두세요.
- 실제 고객에게 문자를 보내는 베타 운영까지 "테스트"로 봐 주는지는 약관에 없어요. 카페24 개발자센터에 미리 물어봐요.

## 보내는 순서

1. 아래 안내문을 보내고, 판매자가 **"동의합니다"**로 답하면 그 메시지를 캡처해 둬요(이메일이면 그대로 보관).
2. 동의를 받은 뒤 설치 링크를 보내요: `https://jjimkkong-psi.vercel.app/api/cafe24/install?mall_id=<쇼핑몰ID>`
3. 판매자가 카페24 관리자에 로그인한 브라우저에서 열고 권한에 동의하면 찜꽁 홈이 열려요.

## 안내문 (그대로 복사)

```
[찜꽁 파일럿 이용 동의]

찜꽁은 카페24 쇼핑몰에서 장바구니 · 공구 알림 신청 고객을 모아 결제 없는 예약 공동구매를 여는 앱이에요.
지금은 카페24 앱스토어 승인 전 파일럿(테스트 설치)이고, 이용료는 없어요. 문자는 쇼핑몰의 카페24 SMS 잔액에서 나가요.

설치 전에 아래 두 문서를 읽고 동의해 주세요.
- 이용약관: https://jjimkkong-psi.vercel.app/terms
- 개인정보 처리방침: https://jjimkkong-psi.vercel.app/privacy

동의하시면 다음 내용에도 함께 동의하시는 거예요.
1. 쇼핑몰 고객 정보(회원 ID, 장바구니 · 공구 신청 내역)의 처리를 찜꽁 운영자(이규현)에게 맡깁니다(개인정보 처리 위탁).
2. 찜꽁은 이 정보를 Supabase(데이터베이스) · Vercel(서버)에 다시 맡겨 처리하며, 저장 위치는 대한민국(서울)입니다.
3. 광고 문자의 보내는 사람은 쇼핑몰이며, 080 무료수신거부 번호와 문자 발신번호를 정확히 등록합니다.
4. 필요하면 쇼핑몰 개인정보 처리방침의 수탁자 목록에 '찜꽁(운영자 이규현)'을 추가합니다.

위 내용에 동의하시면 "동의합니다"라고 답장해 주세요.
```

동의 기록은 파일럿이 끝나고 판매자가 앱을 지운 뒤에도 분쟁에 대비해 보관해 두세요.
