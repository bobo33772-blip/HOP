# 롤롤 개인정보 처리방침 (초안)

> ⚠️ 초안입니다. 출시 전에 `[ ]`로 표시된 운영자 정보를 채우고, 법률 검토를 받은 뒤 공개하세요.
> 시행일: `[YYYY-MM-DD]`

`[운영자 이름 또는 회사명]`(이하 "운영자")는 롤롤(이하 "서비스") 이용자의 개인정보를 소중히 다루며, 「개인정보 보호법」을 지킵니다. 이 방침은 서비스가 어떤 정보를 왜 모으고, 얼마나 보관하며, 이용자가 어떤 권리를 가지는지 설명합니다.

## 1. 수집하는 정보

| 구분 | 항목 | 수집 시점 |
|---|---|---|
| 필수 | 서비스 이용자 식별값(익명 계정 ID) | 앱을 처음 실행할 때 |
| 필수 | 닉네임, 캐릭터 설정(동물·색) | 말랑볼을 만들 때 |
| 필수 | 태어난 해 | 가입할 때 (만 14세 이상 확인용, 다른 이용자에게 보이지 않음) |
| 필수 | 이용 약관(롤롤 약속) 동의 시각 | 가입할 때 |
| 필수 | 촬영한 사진, 촬영 시각 | 사진을 찍을 때 |
| 필수 | 서비스 이용 기록: 열차 탑승, 스티커 반응, 한 줄 방명록, 인사, "또 타요" 선택, 친구 관계, 경험치, 방 꾸미기 설정 | 서비스를 이용할 때 |
| 필수 | 신고·차단 기록 | 신고하거나 차단할 때 |
| 선택 | 이메일 주소 | 계정을 연결하거나 다른 기기에서 불러올 때 |
| 선택 | 푸시 알림 토큰 | 알림을 허용할 때 |

- **위치 정보를 모으지 않습니다.** 사진을 저장할 때 사진에 들어 있는 위치 정보(EXIF)를 지운 뒤 업로드합니다.
- **연락처, 전화번호, 실명을 모으지 않습니다.**
- 서비스 운영 과정에서 접속 기록(IP 주소, 접속 시각, 기기 정보)이 서버에 자동으로 남을 수 있습니다.

## 2. 이용 목적

- 계정 생성과 식별, 만 14세 미만 가입 제한
- 사진 현상·열차 탑승·크루 결성 등 서비스 핵심 기능 제공
- 크루원끼리 사진, 반응, 방명록을 주고받는 기능 제공
- 열차 출발, 인사, 새 친구 등 알림 발송
- 다른 기기에서 계정을 불러오기 위한 이메일 인증
- 신고 처리, 부적절한 콘텐츠 숨김, 이용 제한 등 안전한 이용 환경 유지

## 3. 공개 범위

- **닉네임과 캐릭터**는 같은 열차에 탄 사람과 정거장의 다른 이용자에게 보입니다.
- **사진, 반응, 방명록**은 **같은 열차에 탄 크루원에게만** 보입니다.
- **"또 타요" 선택**은 본인만 볼 수 있고, 서로 고른 경우에만 친구 관계로 알려집니다.
- **태어난 해, 이메일, 신고 기록**은 다른 이용자에게 보이지 않습니다.

## 4. 보관 기간과 파기

- 개인정보는 **이용자가 계정을 삭제할 때까지** 보관합니다.
- 앱의 **내 방 → 계정 삭제**에서 언제든 계정을 지울 수 있습니다. 삭제하면 프로필, 사진 파일, 이용 기록, 친구 관계가 **즉시** 지워지며 되돌릴 수 없습니다.
- 가입만 하고 캐릭터를 만들지 않은 익명 계정은 하루 뒤 자동으로 지워집니다.
- 법령에 따라 보관이 필요한 경우에는 그 기간 동안만 분리해 보관합니다.
